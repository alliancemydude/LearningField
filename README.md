# LearningField

Author: Steven Fry
Email: bomberbub@icloud.com

Learning Field is a program meant to simulate different learning styles in the context of a strategy game. Set what units you would like to comprise your armies into and let them battle. You will recieve detailed, specific feedback on winrates, actions taken, and strategies used. To improve the capabilities of the armies, you can run training sessions. These training sessions put the unit AI through an evolution-style set of battles where your troops will learn what strategies are best for them. 

Army compositions are changed in battlefield.c, then the program is run with entering "make" or "make clean", followed by "./battle". Then follow the text prompts to begin.
